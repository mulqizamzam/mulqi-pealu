# Plugin Listing and Documentation Writer

Write metadata as part of the product contract.

## Procedure

1. Read the manifest and inventory packaged features before writing copy.
2. Describe user outcomes, supported workflows, runtime dependencies and material limitations.
3. Use concrete verbs; avoid unverifiable performance claims.
4. Make runtime compatibility specific. Do not infer verified publisher identity from a username.
5. Use only accurate public URLs and policies; do not invent legal/support pages.
6. Write starter prompts for distinct user jobs.
7. Add beginner steps, uninstall instructions and troubleshooting for installable projects.
8. Distinguish documented steps from actions actually smoke-tested.
9. Track missing publisher metadata, unsupported claims and character limits where relevant.

## Output

Provide exact metadata, validated counts, asset references, starter prompts, documentation status and unresolved limitations.
